## 🚀 Getting Started

You need **Node.js and npm** installed on your system.

### 1. Clone the repository

```bash
git clone https://github.com/Prasahant/REACT_LEARNING.git
```

### 2. Open the project folder

```bash
cd REACT_LEARNING
```

### 3. Navigate to a Vite project

For example:

```bash
cd vite_project
```

### 4. Install dependencies

```bash
npm install
```

### 5. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

**Important:** If you want to run another exercise, navigate to that folder and check whether it contains a `package.json` file before installing dependencies or starting the development server.
